# Tic-Tac-Toe

A clean terminal take on the classic: local two-player games, computer opponents,
and a scoreboard that stays with you between sessions. Python 3.10+, no runtime dependencies.

Development is progressing in stages: game rules and opponents, terminal play and
saved scores, then documentation and release checks.

Run the engine tests:

```bash
python3 -m unittest discover -s tests -v
```
